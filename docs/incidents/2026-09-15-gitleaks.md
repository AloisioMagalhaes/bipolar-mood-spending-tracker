# Incidente P0 — Gitleaks no Actions

- **Sintoma:** `gitleaks/gitleaks-action@v2` terminou com `Unexpected exit code [1]`.
- **Impacto:** job `dependency-audit` falhou e bloqueou a cadeia de build/deploy.
- **Causa provável:** incompatibilidade/erro operacional da action wrapper; OSV Scanner passou e não houve evidência de segredo no log disponível.
- **Correção:** substituir a wrapper por execução do Gitleaks em container oficial, com `detect --source . --redact`.
- **Validação:** reexecutar o workflow após o commit corretivo; issue e PR devem registrar o resultado.
- **Regra:** qualquer erro do Actions permanece P0 até nova execução verde ou diagnóstico documentado.
